# receipt-generator

A simple, polished receipt generator for small business owners.

Features:
- Business and customer details
- Add and remove items dynamically
- Automatic subtotal, tax, discount, and total calculations
- Print-friendly receipt preview
- Minimal static frontend with no dependencies

How to use:
1. Open `index.html` in a web browser.
2. Fill in your business information and line items.
3. Click `Generate Receipt` or edit any field.
4. Use `Print / Save PDF` to create a receipt for customers.

Files included:
- `index.html` – page structure
- `styles.css` – layout and styling
- `script.js` – receipt logic and calculations

This project is ready to customize with your branding, currency, or tax rules.
